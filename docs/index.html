📄 Documentation xtoolav

xtoolav est une application web conçue pour les techniciens audiovisuels en salles de conférence.

🌟 Fonctionnalités

  • 🔌 Calculateur de courant & PoE
  • 🔄 Convertisseur NDI / HDMI / Câbles
  • 🔊 Audio Rechner (dB, SPL)
  • 📏 Bilddiagonalen & Sichtabstand
  • 📡 Netzwerktest & Scanner
  • 📶 Dante Assistant
  • 🔣 ASCII Decoder
  • 📋 Historique & Export PDF
  • 🌍 Multilingue (DE/FR)
